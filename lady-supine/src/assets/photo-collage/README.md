# Idea 30: Hard-cut color specimens

These native image-generation outputs implement the selected photographic concept throughout Lady Supine. Every atlas is 1536×1024, with six 512×512 cells. Thirteen sheets have real alpha for isolated specimens; `materials.png` contains six opaque material photographs. `study.png` is the unchanged selected concept.

The asset registry and cell IDs are in `../../openworld/paperAssets.ts`. The complete sheet table and replacement instructions are in `../../../public/art/README.md`. Images remain native; margin measurement, articulation, texture tiling, and interface thumbnails happen at runtime. Do not rasterize these assets into pixel art.
