# STOCK implementation contract

STOCK is Kilter Kitchen's full polyphonic sampler. A dark commercial kitchen instrument rack with stainless panels, enamel cream, orange signals, and receipt typography; playful kitchen copy with clear practical controls. No external runtime dependency or network request. `schema.js`, `presets.js`, `audio-engine.js`, `zip.js`, `app.js` are inline in a standalone HTML. The common Samples module is embedded at build time.

## Schema (window.FableSchema)

VERSION 1.0.0; MAX_ASSETS 32, MAX_ZONES 64, MAX_SECONDS 120, MAX_PCM_BYTES 64 MiB (decoded Float32 mono/stereo), MAX_PROJECT_BYTES 64 MiB JSON. Assets encoded 16-bit interleaved base64 for portable state; accept 8–192k rates and finite mono/stereo. Seed assets `{id,kind:'seed',name,recipe,seed,duration,sampleRate:24000,channels:2,root}` generate actual sample buffers once. Imported assets `{id,kind:'pcm',name,sampleRate,channels,frames,duration,pcm,root}`. Recipe IDs: bell, felt, reed, tape, choir, dust, sub, kit.

State `{version,name,tempo:104,swing:.08,seed,selectedZone,selectedPattern:0,keyOctave:4,assets,zones,master,lfos,modulation,performance,patterns}`. `selectedZone` is a zone string ID. `patterns` four patterns `{name,length:16,steps:[64 steps]}`; length supports16/32/64. Steps `{on,note:60,velocity:.8,gate:.7,probability:1,ratchet:1}`. gate is proportion of a sixteenth-note; division is .25 beats for sequencer.

Zone `{id,name,assetId,enabled,color,root:60,low:0,high:127,velLow:1,velHigh:127,transpose:0,tune:0,tracking:true,level:.85,pan:0,width:1,start:0,end:1,loopStart:.1,loopEnd:.9,loopMode:'off',crossfade:.012,reverse:false,playMode:'gate',engine:'classic',stretch:1,grainSize:.08,grainDensity:12,jitter:.03,position:0,choke:0,roundRobin:0,envelope:{attack:.003,decay:.25,sustain:.8,release:.35},filter:{type:'lowpass',cutoff:18000,q:.7,drive:0,keytrack:0,velocity:.2,amount:0,envelope:{attack:.006,decay:.3,sustain:0,release:.15}}}`. start/end/loopStart/loopEnd/position normalized0–1; crossfade andgrainSize seconds. loopMode off/forward/pingpong; engine classic/texture (real granular time/pitch independent scanning); choke androundRobin0–8,0off. Filter types lowpass/highpass/bandpass/notch. amount filter envelope octaves.

Master `{level:.7,transpose:0,tune:0,polyphony:32,bendRange:2,velocityCurve:1,drive:.1,chorus:.1,delay:.15,feedback:.3,delaySync:.5,space:.2,tone:18000,width:1}`. delaySync beats. Two LFOs `{shape:'sine',rate:.8,sync:false,division:1,depth:1,retrigger:true}`; shapes sine/triangle/square/random. Eight routes `{source:'off',target:'pitch',amount:0}`; sources off,lfo1,lfo2,velocity,key,wheel,pressure,random,envelope; targets pitch/cutoff/pan/level/start/position. Amount signed normalized-1..1 (engine defines musically useful ranges). Performance `{mode:'sequence',arpMode:'up',hold:false,octaves:1,division:.25,gate:.7,velocity:.8}`; mode sequence/arp; arp up/down/updown/random/asplayed/chord.

Schema methods defaultState(),normalize(state),parseProject(text),serializeProject(state),copy(value) (recursive immutable string reuse, avoid JSON clone for Undo),uid(prefix),createZone(asset,overrides={}),encodeAsset({pcm:interleavedStereoFloat32Array,sampleRate,name,root}) returns PCM asset,decodeAsset(asset) returns `{left,right,sampleRate,duration}` for PCM only,detectPitch(audio) returns `{note,cents,confidence,frequency}` or null,trimSilence(audio,thresholdDb=-42) returns normalized `{start,end}`,onsets(audio,count=16) returns ordered normalized boundaries,autoMap(zones,mode='keys'|'velocity'|'drums') returns new zones preserving assets/edits. Pitch analyzes strongest channel; imported base64 byte dimensions validated before allocations. Strict project rejection, no silent audio loss/clamping malformed metadata.

## Presets

window.FablePresets = array eight `{id,name,description,create:()=>state}` with distinct audible multi-zone or velocity/round-robin patches and musical64step arrays (length16 default). No app/server references. Synthetic seed recipes are sampled buffers, not oscillators used in lieu of imported samples.
