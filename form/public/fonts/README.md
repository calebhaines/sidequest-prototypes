# Bundled fonts

FORM bundles these Latin variable WOFF2 fonts so typography works without requests to an external font service:

- `dm-sans-latin-variable.woff2` — DM Sans, normal style, CSS weight range **400–700**. License: `DM-Sans-OFL.txt`.
- `space-grotesk-latin-variable.woff2` — Space Grotesk, normal style, CSS weight range **400–700**. License: `Space-Grotesk-OFL.txt`.

Both fonts are distributed under the SIL Open Font License 1.1. Preserve the included copyright and license notices when redistributing the app or embedding fonts in a standalone HTML file.

Downloaded October 3, 2026 from the official Google Fonts CSS2 API and Google Fonts repository:

- [DM Sans CSS2 metadata](https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&display=swap)
- [DM Sans Latin WOFF2](https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2)
- [DM Sans license](https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/OFL.txt)
- [Space Grotesk CSS2 metadata](https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400..700&display=swap)
- [Space Grotesk Latin WOFF2](https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2)
