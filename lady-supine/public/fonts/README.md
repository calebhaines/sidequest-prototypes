# Fonts for the downloadable game

These unmodified WOFF2 files are DM Sans, Kalam, and Libre Baskerville, cached from Google Fonts on 2026-10-13. Each family is distributed under the SIL Open Font License 1.1; the original notices are in the adjacent `*-OFL.txt` files.

`fonts.css` preserves Google Fonts' font-face weights, styles, and Unicode subsets. The single-HTML build reads these local files and embeds them as data URLs, so rebuilding and playing the download require no font server. The hosted game can continue to use its ordinary stylesheet links.

Sources:

- https://fonts.google.com/specimen/DM+Sans
- https://fonts.google.com/specimen/Kalam
- https://fonts.google.com/specimen/Libre+Baskerville
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/kalam
- https://github.com/google/fonts/tree/main/ofl/librebaskerville
