STATION OPERATING INSTRUCTIONS

Keep the reduction moving.

REDUCE sends short sounds through four interconnected delay and resonator processors. Their outputs can return to themselves or travel to other nodes. Filtering, saturation, and modulation reshape each trip. Feed the circuit carefully; the recipe will continue developing.

Add a sound

Choose one of four source lanes and edit its sound. Click a step to add a hit; Shift + click gives it an accent. Right click, long press, or Alt + Enter opens velocity, probability, and ratchet settings; Step settings opens the last selected step. Trigger source auditions immediately. Import sample loads a sound into the selected source; Microphone enables live input into its selected node when your browser permits it. Imported samples use the first ten seconds.

Shape a return

Select a feedback node, choose its processor model, then adjust its controls. Time changes delay length; Sync time follows the tempo and division. Pitch tunes resonators; damping darkens each return. Routing rows send into columns. Diagonal values return a node to itself. Sends above a combined 100% are balanced within that row; Circulation controls the overall feedback amount.

Keep it moving

Two LFOs add continuous movement. Choose a destination, wave, rate, and depth. Assign the X and Y field to performance destinations. Performing on a time destination switches that node to free delay time. Freeze holds the sound already in each node and suspends new input. Panic immediately silences the network and stops playback.

Keep the batch

Save project downloads an editable JSON file including your imported sample. Record output captures what you play live. Export WAV renders the sequence with its feedback tail. Changes save in this browser when storage is available.
