# Native torn-paper cutouts

These PNGs were generated for the playable Lady Supine game to closely reproduce [the selected torn-paper study](../../../public/style-studies/03-torn-paper.png).

Five transparent 1536×1024 sheets contain 30 isolated cutouts in 3×2 grids: all 18 character heads, six scenery pieces, and six articulated clothing/wing/arm components. `study.png` is the unchanged original direction sheet.

See [the art guide](../../../public/art/README.md) for cell ordering, loading, animation, palette direction, and replacement requirements. Native source pixels are preserved; cropping and articulation happen only when the game draws the sheets.
