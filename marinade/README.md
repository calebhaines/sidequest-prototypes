# MARINADE · Kitchen

Two sounds. One very unusual soak.

MARINADE is a polyphonic spectral morphing instrument. It analyzes two source clips
and resynthesizes their changing partials, with independent spectral amplitude and
frequency blending, residual texture, a transient layer, frozen or moving sample
positions, formant shaping, a drawable morph path, envelopes, modulation, and
stereo effects. A 1–32-step note sequencer and keyboard make the result playable.

All factory source audio is generated by original deterministic synthesis code;
no third-party recordings or runtime downloads are required. Imported samples are
converted to mono 22,050 Hz PCM for spectral analysis and embedded in portable
projects. Each source accepts up to twenty seconds of audio.

Open `index.html` in a browser, choose a recipe, and press Play or a key. The same
file works offline, with its interface, source sounds, and sample/pattern exchange
code embedded. The app begins audio after a playback or keyboard gesture.

Source analysis uses a 2,048-point Hann FFT, up to 96 time frames, and 72
frequency lanes aligned relative to each source's root note. This alignment keeps
different source pitches tuned when blended. A smoothed spectral envelope shapes
formants separately from the partial frequencies. Six residual noise bands and
the original short attack provide additional texture and transient character.

The engine supports sixteen voices. It retains 36 strong partials per voice for
up to eight simultaneous voices, then shares a 288-partial budget with smooth
fades. Parameter updates run every 128 samples; note starts and releases retain
sample timing. Imported sample bytes stay in the project and analysis cache, so
ordinary knob changes send only the small synthesis state to the audio processor.

## Build and checks

Python 3's standard library is the only build dependency:

```sh
python build.py
python build.py --output /tmp/marinade.html --archive /tmp/MARINADE-source.zip
node engine-checks.cjs
node browser-checks.cjs
```

Browser checks use Playwright and Chromium when available. In the site checkout,
run `python marinade/build.py`, `python loom/build.py`, then `npm run build` to
refresh the instrument, GALLEY's embedded copy, and GitHub Pages files.

Source modules load in this order: schema, sequence, sources, presets, analysis,
audio engine, app, adapters. Live audio and WAV/GALLEY rendering use the same pure
DSP core. GALLEY receives native stereo Float32 PCM for printing, preserving
duration even when its audio context runs at another sample rate.

Samples receives audio into Source A or B and contributes rendered notes, chords,
or phrases. Patterns exchanges editable notes and preserves imported fractional
timing in an exact performance overlay. Hosted state includes both source audio
and the complete patch; Print, Edit source, and Restore notes remain reversible.

The release can be reverted using the checkpoint and guide in
`music/ROLLBACK.md` in the site repository.

## Longer patterns

The existing Steps control now accepts up to 32. Above sixteen, the compact
1–16 / 17–32 buttons page the existing grid and step inspector. Shortening keeps
hidden notes in projects, recovery and GALLEY state. Clear, All on, note recipes
and seasoning affect only the active length, so hidden notes are retained.
Factory recipes and older projects still default to sixteen steps with identical
timing. The morph path remains its independent sixteen-point movement curve.
Portable pattern exports include the complete active phrase at its chosen rate;
WAV exports still use musical bars, so choose enough bars for the phrase.
