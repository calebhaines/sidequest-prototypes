# CHAR · fifteen ways to turn up the heat

The **Circuit** menu now offers fifteen choices. The original **Soft saturation**,
**Asymmetric diode** and **Wavefolder** retain their released processing exactly.
Existing projects keep their controls and sound.

The twelve additions are distinct transfer and response models, not preset names
for the same shaper:

| Circuit | What to listen for |
| --- | --- |
| Hard clip · silicon | A firm ceiling, bright edges and compact peaks. |
| Cubic overdrive | A polynomial knee that gradually reaches a flat ceiling. |
| Round drive · arctan | A broad, gradual saturation knee with softer density. |
| Rectifier · octave up | Full-wave rectification adds strong even harmonics and an upper octave. |
| Class-A valve | Asymmetry, a gently moving overload point and a softened upper range. |
| Push-pull · crossover | A cold complementary stage leaves a small notch around zero. |
| Transistor fuzz | Pre-emphasis and unequal clipping give a forward, grainy fuzz. |
| Op-amp · feedback drive | Mid-focused pre-emphasis and rational limiting tighten the sound. |
| LED clip · wide headroom | More attack passes before a wider clipping knee; turn Drive up further for heavier clipping. |
| Starved fuzz · gate | A strong fuzz closes its envelope gate as notes decay. |
| Sine fold | Smooth periodic folding changes the harmonic balance as Drive rises. |
| Broken transistor | Unequal clipping, bias drift and memory-dependent headroom make a darker, sagging edge. |

**Drive** moves the source into each circuit's knee. **Bias** changes symmetry,
**Tone** sets the upper range, and **Output** sets the serving level. **Dry / wet**
adds parallel colour. Different circuits have different headroom and frequency
responses, so use Output when comparing their character at similar loudness.

The twelve new choices use four-times oversampled nonlinear processing, an
anti-alias filter before returning to the host rate and DC cleanup. Control
changes are smoothed, and circuit changes bridge over five milliseconds. There
is no added fixed audio delay. Gated fuzz intentionally changes the envelope of
a note and may close on quiet input.

These are original reduced-order musical circuits, not measured replicas of
individual pedals or amplifiers. The circuit choice is retained in portable
projects, instrument voice patches and WAV exports. CHAR remains one effect
slot, with the same compact controls and automation targets.
