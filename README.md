# Sidequest

Four original browser RPG prototypes with classic top-down pixel art, real-time combat, exploration, dialogue, quests, loot, and character progression.

## Download and play

[Play in your browser](https://calebhaines.github.io/sidequest-prototypes/) · [Download all four prototypes](https://raw.githubusercontent.com/calebhaines/sidequest-prototypes/v0.1.0/docs/sidequest-prototypes.zip) · [Releases](https://github.com/calebhaines/sidequest-prototypes/releases)

Use the download link above or the links on this repository's **Releases** page to save **sidequest-prototypes.zip**. Extract it and double-click **sidequest/PLAY.html**, or open that file using your browser's Open File command. Everything needed to play is bundled, and all four prototypes work offline without an installation or server.

You can also download **sidequest-play.html** from the release, save it to your device, and open the saved HTML file directly.

## Choose a world

- **Moss & Myth** — woodland fantasy, forest folk, and forgotten magic.
- **Neon Afterglow** — cyberpunk streets, shady jobs, and faction choices.
- **The Dustlands** — desert salvage, lost technology, and a settlement's water crisis.
- **Borrowed Sky** — surreal suburbs, everyday magic, and a town frozen in time.

These are small playable concept slices for selecting a setting to expand into a larger RPG.

## Controls

WASD or arrow keys: move. Shift: sprint. E or Enter: talk or interact. Space: attack. M: world map. Escape: close dialogue or map, or return to the gallery. Touch controls appear on small screens. Ambient sound is optional.
